# 実験を確定する手順

1. コード・教材・設定を準備し、教師の復元と小テストを通す。
2. 実装・設定・教材のハッシュを固定し、実行したソースのスナップショットを保管する。
3. 起動後は参照されるファイルを編集しない。修正は新しい実験名と別のスナップショットで行う。ローカルの現在版を、実行済みの版と同一と推測しない。
4. リモートへ転送した直後にコード・設定・教材のハッシュを照合する。実行時のconfigに記録されたprotocolのハッシュを、回収した実行版と照合する。
5. 重み・履歴・設定・データを回収し、チェックポイントだけでなく実行版の一致も検査する。不一致は保存したうえで原因を確認し、必要なら条件を揃えて再実行する。
6. 学習・評価を `a_gpu_session.py` の回収・照合・割り当て解除の処理で包み、終了後にAzureの状態を直接確認する。次のGPU実験は、前の終了と割り当て解除を確認してから始める。

11/20は最終照合で、初回Mu実験とローカル現在版の勾配スケール初期値の差を検出した。実行版をハッシュ一致で復元し、元結果を保持して対照2回を再実行した。初回予備2回を、細分類だけが違う比較として扱わない。最終検査は `scripts/a_feedback20_verify.py`。
